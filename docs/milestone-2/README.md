# `docs/milestone-2` — Your Company's Public Website

Documentation of Milestone 2, which builds Nexova's public website at the repository root: a landing page and a talent pool application form, in plain HTML, compiled Tailwind CSS and vanilla JavaScript, in English (base) and Spanish (`es/`). The milestone briefing is [`BRIEFING.md`](../../BRIEFING.md) at the root.
